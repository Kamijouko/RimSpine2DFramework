## About the project

RimSpine2DFramework brings Spine 2D animation support to **RimWorld** mods, enabling smooth skeletal animation for custom pawns and objects. The repository contains C# source code, XML definitions, and reference documentation used to integrate Spine assets into the game engine.

Explore the localized READMEs for detailed guidance tailored to each language.
